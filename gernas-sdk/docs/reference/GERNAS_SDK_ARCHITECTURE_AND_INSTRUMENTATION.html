What each part does

Gernas SDK
The central toolkit (pip install gernas-telemetry, import gernas): one init call, decorators and adapters that emit blueprint-named spans, metrics and logs, context propagation, PDPL redaction. No vendor SDK; OTLP only.
Agent Mesh
The reference use case. It consumes the SDK through one integration module (src/observability/gernas_telemetry.py) and decorators at its business seams.
OpenTelemetry Collector
The gateway: receives OTLP, applies the PDPL denylist and allow-list, samples, reshapes for Opik and fans out to Opik and the ADX data plane.
Opik
Developer trace view (traces only).
ADX
The data plane for traces, metrics and logs (dashboards and KPIs are computed there).
